# FácilDigital — Guías completas

Se han preparado 16 páginas de guías con un diseño común y responsive.

Cada guía:
- comparte los colores y tipografía visual de FácilDigital;
- incluye cabecera y footer coherentes;
- funciona en escritorio y móvil;
- contiene explicaciones, pasos, consejos y comprobaciones;
- incluye fuentes oficiales cuando se han utilizado para verificar procedimientos;
- no requiere servidor ni dependencias.

Abre `index.html` del proyecto principal y enlaza estas páginas desde la carpeta `guias/`.
